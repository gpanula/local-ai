# Loom Execution Harness

**Reference**: [sfw/loom on GitHub](https://github.com/sfw/loom)

This directory is dedicated to setting up, configuring, and experimenting with the **Loom** AI harness connected to our local Ollama instance (`http://127.0.0.1:11434`).

## Topics & Artifacts
* Loom repository clone / installation
* Config (`config.toml`) mapping planner, verifier, executor roles to local models
* Multi-step execution logs, subtask traces, and verification tests
